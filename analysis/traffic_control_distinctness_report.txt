# TC+ Distinctness and Traffic Response Diagnostic

Diagnostic-only. Regular-season scoped through scripts/data_integrity.py. Base state = first pitch of PA; outcome = terminal pitch.
Gates: IP >= 40, men-on PA >= 50, RISP PA >= 25. Split-half uses odd/even pitcher games with relaxed half gates: men-on PA >= 25, RISP PA >= 12.
TC+ here is plus-scaled `100 * (K% - BB%) / xWHIP_lgBABIP` within each role scope.

## Recommendation
- Baseline TC+ is too close to K-BB% by the pre-registered rule (r=0.982); do not ship the quotient as the headline.
- Command+ and Traffic+ are fairly collinear (r=0.851); the quadrant needs caution.
- Men-on K-BB has a clear strand-skill gap versus LOB proxy (LOB vs men-on K-BB r=0.211), so LOB% should remain context/mirage, not an input.
- Men-on/RISP split-half stability is not strong enough for a precise headline score yet (men=0.335, RISP=0.168); use as texture/badge.
- Predictive WHIP optimization was not reopened.
